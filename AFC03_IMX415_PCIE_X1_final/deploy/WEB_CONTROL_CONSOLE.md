# FPGA 本地网页控制台连接说明

本版网页用于控制 RK3576 视频播放、YOLO、截图和录像，**不传输实时视频**。视频仍从板卡 HDMI 输出。电脑与板卡用网线连接时，可同时使用 Xftp、PuTTY 和网页控制，不需要蓝牙或 4G。

## 一、用 Xftp 更新板端文件

将电脑 deploy 文件夹中的文件上传到板卡现有目录 `/home/linaro/deploy`，不要多套一层 deploy 目录。请至少上传：

- `web_control_board.sh`
- `play_raw_video.sh`、`play_lz77_video.sh`
- `video_capture_ctl.py`
- 整个 `control_console` 文件夹
- `SHA256SUMS`（与本次更新文件配套）

如果网页控制器里的板端目录填写的不是 `/home/linaro/deploy`，请把文件放到对应目录，并在网页中填写同一路径。

## 二、设置 Windows SSH 密钥登录

网页服务通过 Windows 自带的 SSH 程序连接板卡。为了不把 SSH 密码保存在网页或配置文件中，首次使用需要设置密钥登录。Xftp 继续用原来的会话和方式即可。

1. 在 Windows 开始菜单打开 **PowerShell**，运行：

   ```powershell
   ssh-keygen -t ed25519
   ```

   保存位置使用默认值。设置密钥密码时，如果希望网页点击按钮后不再等待输入，可直接回车留空；如果设置了密钥密码，请先配置 Windows SSH 代理并解锁密钥。

2. 打开 Xftp，连接板卡当前 IP 和 SSH 用户。你截图中的用户名是 `linaro`，因此将公钥文件 `%USERPROFILE%\.ssh\id_ed25519.pub` 上传到 `/home/linaro/id_ed25519.pub`。只上传以 `.pub` 结尾的**公钥**；不要上传或发送 `id_ed25519` 私钥。

3. 用 PuTTY 登录板卡，使用与网页相同的用户名，运行以下命令，将公钥加入允许登录列表：

   ```bash
   mkdir -p ~/.ssh
   chmod 700 ~/.ssh
   cat ~/id_ed25519.pub >> ~/.ssh/authorized_keys
   chmod 600 ~/.ssh/authorized_keys
   ```

4. 回到 Windows PowerShell，运行测试命令。用户名使用 `linaro`，IP 换成板卡**当前** IP：

   ```powershell
   ssh linaro@192.168.137.194
   ```

   第一次连接会询问是否信任主机指纹；确认这是自己的板卡后输入 `yes`。如果成功登录，输入 `exit` 返回 Windows。以后板卡 IP 改变时，在网页里改成新 IP；若系统提示主机指纹变化，先用 PuTTY/PowerShell 核对设备身份，再更新记录。

## 三、启动网页

1. 在电脑上双击 `control_console/start_control_console.bat`。
2. 浏览器会自动打开网页。如果没有自动打开，请手动访问：

   ```text
   http://127.0.0.1:8765
   ```

3. 在“设备连接”填写板卡当前 IP、SSH 用户名（默认 `linaro`）、端口（通常是 `22`）和板端 deploy 目录；这些设置会保存在当前浏览器中。默认 IP `192.168.137.194` 只是初始值，不要求固定使用。
4. 点击“连接测试”。显示连接正常后即可选择原图或 LZ77、FPGA 模式，并启动或停止播放。

启动网页后要保持黑色命令窗口运行；关闭该窗口会停止本机网页服务。服务只监听本机地址 `127.0.0.1`，局域网其他设备无法打开此控制页面。

## LZ77 DMA 等待预算：网页直接控制

“播放控制”中新增“LZ77 DMA 等待预算”，可选 **0（关闭）、10、20微秒**。
初始推荐20微秒，选择保存在当前浏览器；已保存其他值时继续使用已保存值。

1. 数据链路选择“BLK1 / LZ77 解码”，选择模式（0～6、8或9）。
2. 预算选择“20微秒 · 推荐配置”。点击“启动播放”时，板端先关闭驱动阶段计时，
   写入预算并读回确认，再启动已有播放器；仍使用完整CRC和4KiB DMA read。
3. 播放过程中可改选0、10或20并点击“应用预算”，不重启播放，也不停止录像。
   该操作只改参数，不会启动另一个播放器。写入作用于后续符合条件的请求；
   已经在途的请求可以继续使用它开始时读取的预算。
4. “连接测试”或“刷新状态”会读取**板端实际值**，显示在预算下方。
   下拉框是希望应用的值，下面的“板端当前值”才是读回结果，两者不会自动混为同一状态。
5. RAW/V4L2链路不使用此等待优化，选择RAW后禁用预算控件，启动RAW不会修改板端现有预算。

板端须已加载包含`st_c2h_wait_spin_us`的候选驱动。本次用户板卡已完成驱动编译、加载和板测，
只更新网页和板端控制脚本即可，无需重新编译驱动、重载驱动或烧录bit。
如果板卡重启后加载了旧驱动，页面会显示“不支持”，不会把20微秒静默当作生效；
可选择0继续使用原等待路径，或按`DMA_WAIT_20261025.md`加载候选驱动。

20微秒适用于所有支持模式的LZ77字符设备4KiB路径，mode8的stats/KMS实测显示与检测均约20 FPS；
其他模式的具体增益及长时间负载仍应分别验证。20微秒是等待预算，不是额外增加20微秒固定延迟。

参数在停止播放后保留，驱动重载/重启后默认回0。再次从网页启动LZ77会应用浏览器所选值。
这次没有修改驱动内置默认值或增加开机常驻服务。模块参数会影响同一驱动中符合条件的其他读取，
测试期间不要再从其他程序同时改动该参数。

### 已在使用旧网页时如何更新

在Windows电脑上，用本次deploy中的整个`control_console`替换你实际启动的控制器目录。
用Xftp上传配套`web_control_board.sh`和SHA256SUMS到开发板`/home/linaro/deploy`，
其他deploy文件若已有同版校验值无需重复上传，保留现有工作`.ko`及模型。

停止旧播放后，在**连接开发板的PuTTY窗口，root登录状态**执行：

```bash
cd /home/linaro/deploy
sha256sum -c SHA256SUMS
```

在**Windows电脑**关闭原来运行网页服务的黑色窗口，再双击新目录中的
`control_console/start_control_console.bat`。浏览器打开后按 **Ctrl+F5** 刷新，
确认“LZ77 DMA 等待预算”控件出现，再进行连接测试。
不能只刷新浏览器而继续运行旧Python服务，因为新增操作需要本地服务和板端脚本共同支持。

本次已通过HTTP/SSH命令参数回归、前端状态逻辑测试，以及隔离文件系统中的实际板端shell
写入/读回/播放中修改/RAW隔离/旧驱动回退测试；最终网页到实际板卡的联调仍需本次更新后确认。

## 四、截图和录像

启动播放后，网页上的“截图”“开始录像”“停止录像”和“录像状态”按钮通过现有采集控制接口操作。文件保存在**板卡 TF 卡**的 `/mnt/tf/FPGA_Captures`。使用前需要确认 TF 卡已经挂载并且目录可写。停止录像只结束录像，不会停止视频播放。

网页使用 `linaro` 账户建立 SSH 连接；板端固定控制桥会先检查 `sudo -n`，再以 root 权限访问 `/dev/mem` 和视频设备。`linaro` 必须已有免密码 sudo 权限，否则播放控制会报权限错误。网页不保存 sudo/SSH 密码。网页不显示 HDMI 画面，也不提供视频预览；本机状态区域显示连接结果、播放信息和板端日志。

如果点击“连接测试”提示认证失败，请先完成第二节的密钥配置。如果提示找不到 `ssh.exe`，请在 Windows“可选功能”中安装 **OpenSSH 客户端**。启动网页时若提示找不到 Python，请安装 Python 3 并重新启动。

> 若板卡已由 PuTTY 手动启动了播放或 C2H 接收，不要再从网页重复启动；先停止现有进程，再由网页统一控制。
