# FPGA 本地网页控制台

Windows 本地网页控制器的完整中文连接、密钥设置和使用步骤请阅读同级文件 `../WEB_CONTROL_CONSOLE.md`。

快速启动：确认 Python 3 和 Windows OpenSSH 客户端可用，双击本目录中的 `start_control_console.bat`，浏览器打开后填入板卡当前 IP 并点击“连接测试”。默认 SSH 用户名为 `linaro`；默认访问地址是 `http://127.0.0.1:8765`，默认板卡 IP `192.168.137.194` 可在网页修改。

网页只提供控制和状态，不传输视频；视频仍从板卡 HDMI 输出。截图和录像保存到板卡 TF 卡 `/mnt/tf/FPGA_Captures`。Xftp 可以同时使用。

播放控制新增“LZ77 DMA 等待预算”，可选0/10/20微秒，初始推荐20微秒。
选中LZ77时，启动播放自动应用所选值；播放中可点击“应用预算”直接切换，不重启视频。
连接测试/刷新状态读取板端实际值，所选值与实际值分别显示。RAW启动不修改此参数。
板卡需已加载含`st_c2h_wait_spin_us`的候选驱动，旧驱动可选0继续使用原路径。
停止播放后参数保留，驱动重载/重启后回默认0；再次从网页启动LZ77会重新应用所选值。
更新后请关闭电脑上原网页服务的黑色窗口，重新双击本目录`start_control_console.bat`，
并在浏览器按Ctrl+F5刷新。板端须同步更新`web_control_board.sh`及SHA256SUMS。
