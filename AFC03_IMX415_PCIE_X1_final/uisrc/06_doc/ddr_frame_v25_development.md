# PCIe v25：DDR 启动保护与中值/Sobel 移植

版本寄存器 BAR0+0x5C：`0x56440025`。在原 `imx415_pcie_4k.al` 上开发，
不另建 fix 工程。MIPI 源工程及旧 v23/v24 发布包保持原样。

## 模式与数据路径

模式 0～4 保持原行为（含均衡 LUT 亮度平滑），新增：

| 源 MIPI VPI 命令 | PCIe BAR0+0xA4 | 功能 |
| --- | --- | --- |
| 11110101 / F5 | 5 | 灰度＋3×3 中值降噪 |
| 11110110 / F6 | 6 | 灰度＋3×3 Sobel 二值边缘 |
| 未分配 | 7 | 预留，脚本拒绝使用 |

Sobel 使用 `abs(Gx)+abs(Gy)>128` 输出 255，否则输出 0。阈值 128 是
编译参数，未增加运行时阈值寄存器。中值不是边缘检测，两者并列选择，
不是串联；模式 6 不自动经过中值滤波。

摄像头/ISP → 灰度及所选滤波 → RGB24 打包 → DDR 完整帧双槽 → LZ77
→ PCIe C2H。每拍四个灰度像素，输出复制到 R/G/B，1080p 每帧仍为
6,220,800 字节，现有 RK 接收解码器无需改协议。
模式 5/6 当前仅在 1920×1080 的预处理路径启用；其他分辨率沿用旧旁路。

滤波使用复制边界，不裁剪尺寸。无输入反压，帧末至少需要 W/4+5 个
时钟排空底行。摄像头端是否始终满足这一条件仍需板上计数验证。

## 启动保护与错误观测

继承 v24：每次捕获启用后，跳过第一个观察到的帧；第二个 SOF 与首个
数据字一起进入 DDR。捕获帧号包含主动跳过帧。此保护用于验证 v23
启动帧假设，未证明实际根因，也不取消运行期间的完整帧检查。

| BAR0 偏移 | 含义 |
| --- | --- |
| F0 | 主动启动跳过帧数；软复位后的单次测试预期为 1 |
| F4 | 中值模块协议错误计数 |
| F8 | Sobel 模块协议错误计数 |

D4 保持槽位忙整帧跳过计数；D8 保持 DDR 无效帧拒收计数。测试脚本
继续要求 DDR/压缩/丢数计数为零，并检查当前所选新滤波分支错误为零。
预处理各分支并行运行，未选中分支的计数仅供诊断；F4/F8 不因模式切换
自动清零，软复位时清零。保留 before_stop.log 和 ddr_timeline.log。

## 验证结果

- 新模块按源工程 SHA256 核对；源算法未修改，移植的是两个 RTL 算法
  及输出选择，未移植源 VPI 控制或 MIPI 发送端。
- 模式 5/6 的 4×2、8×4、16×6 各五帧，1080p 各两帧连续输入，逐像素
  和 SOF/EOL 与独立 Python 参考匹配，协议错误为零。
- 模式 0～6 所有有序切换对，99 帧小图，帧内请求不改变当前帧。
- 两个模式各经实际 RGB24 打包、DDR AXI 行为模型、LZ77，再由 RK Python
  解码器核对四帧像素/CRC/尺寸及帧号 1～4。启动帧 0 主动跳过。
- 原 C2H 100 帧、背压、包边界、异常帧和 FIFO 回归通过。
- 完整综合通过，综合估计 slice 50.36%、ERAM 193/272、DSP 64/240。

测试脚本：edge_port/run_edge_port.ps1、edge_port/run_edge_ddr.ps1、
c2h_regression/run_frames.ps1（均位于 uisrc/02_sim）。
10ns 仿真激励只证明功能，不表示硬件已满足 125MHz。
TD 完整综合、布局布线、bitgen 已于 2026-10-08 完成。
最终 setup WNS -23.579 ns、TNS -14975.729 ns；hold WNS -1.168 ns、
TNS -8.700 ns。时序未闭合，实现阶段仍有 ERAM 异步复位相关严重警告，
以及 MIPI 时钟混合扇出、DDR BUFG 级联和 PCIe 时钟请求值/实际值不一致
（62.5/125 MHz）的告警。时序优化也报告因最差裕量过差而中止部分优化。
因此仅为功能调试版，不是稳定发布或时序签核版本，尚未上板验收。
发布包位于 imx415_pcie_4k_Runs/debug_release_ddr_v25_20261008。

## 上板步骤

烧录最终 v25 位流后，将同一发布包 deploy 目录内三个脚本覆盖复制到
RK 的 /home/linaro/deploy，保持现有 lz77-rx-geometry-20261006b 接收程序。
停止 GStreamer、dd 和其他 C2H/V4L2 使用者，在单终端执行：

```bash
cd /home/linaro/deploy
bash pcie_setup.sh
bash test_lz77_frames.sh 0x21200000 3 1
bash test_lz77_frames.sh 0x21200000 3 5
bash test_lz77_frames.sh 0x21200000 3 6
```

每个命令单独检查结果，出现错误就保留日志再定位。预期每次 frames=3、
receiver_exit=0、test_exit=0，RGB24 长度一致，各完整性错误计数为零。
DDR_STARTUP_SKIPS=1，DDR_NO_SLOT 可以非零。不承诺每个摄像头曝光均
被压缩，日志 fps 含启动/等待开销，不等于摄像头原始帧率。

先通过三帧，再重复同模式验证启停、再跑较长测试。如用 linaro 登录
Xftp 无法打开 root 创建的日志目录，可在 root 终端对本次唯一目录执行
chown -R linaro:linaro /tmp/lz77-diag.实际后缀，再刷新 Xftp。
不要修改整个 /tmp 的权限。设备树和 Linux 驱动不需要因本次移植修改。
